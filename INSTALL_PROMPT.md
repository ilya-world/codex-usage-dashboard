# Промпт для установки

Отправьте этот промпт Codex на компьютере, где вы пользуетесь Codex:

```text
Установи мне Codex Usage Dashboard из публичного репозитория
https://github.com/ilya-world/codex-usage-dashboard.

Сделай всё самостоятельно:
1. Клонируй репозиторий в подходящую постоянную папку на этом Windows-компьютере.
2. Прочитай README.md и проверь, что локальная папка %USERPROFILE%\.codex существует.
3. Запусти install.ps1 через Windows PowerShell. Если мешает Execution Policy, используй Bypass только для этого запуска.
4. Убедись, что создался локальный снимок data\codex-token-usage-data.js и задача планировщика CodexTokenUsageSnapshotRefresh.
5. Проверь, что задача обновляет данные каждый час, а параллельные запуски не накладываются.
6. Открой codex-token-dashboard.html и проверь, что отображаются мои локальные треды, токены и недельный лимит.

Не отправляй мои данные Codex во внешние сервисы и ничего из data, logs или сырых JSONL-сессий не добавляй в Git. В конце коротко сообщи путь установки, время последнего снимка и время следующего автоматического обновления.
```
