# Codex Usage Dashboard

Локальный HTML-дэшборд для анализа потребления токенов Codex. Он читает
локальные журналы сессий, строит снимок данных и открывается обычным HTML-файлом:
без сервера, облачной базы, API-ключей и телеметрии.

> Проект не является официальным продуктом OpenAI. Формат локальных журналов
> Codex может меняться, поэтому расчёты лимитов зависят от доступных событий
> rate limit в ваших сессиях.

## Что показывает

- оставшийся недельный лимит в виде батареи;
- недельный burndown: фактический расход и равномерный ориентир;
- динамику токенов по дням и часам;
- долю недельного окна, использованную в каждый день;
- входные, выходные, cached, reasoning и прочие токены;
- статистику по рабочим папкам и тредам;
- кросс-фильтрацию по дню, часу и папке;
- время фактического снимка данных.

## Установка одним промптом

Откройте Codex на Windows и отправьте ему промпт из
[INSTALL_PROMPT.md](INSTALL_PROMPT.md). Codex клонирует репозиторий, создаст
первый локальный снимок, зарегистрирует почасовое обновление и откроет дэшборд.

## Ручная установка

Требования:

- Windows 10 или 11;
- Codex уже запускался хотя бы один раз;
- локальные данные Codex находятся в `%USERPROFILE%\.codex`;
- Windows PowerShell 5.1 и Task Scheduler.

```powershell
git clone https://github.com/ilya-world/codex-usage-dashboard.git
cd codex-usage-dashboard
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Установщик:

1. создаёт первый снимок;
2. регистрирует задачу `CodexTokenUsageSnapshotRefresh`;
3. запускает обновление каждый час и при входе в Windows;
4. не допускает наложения параллельных обновлений;
5. открывает `codex-token-dashboard.html`.

Администраторские права обычно не требуются.

## Ежедневное использование

Открыть дэшборд и предварительно обновить данные:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\open-codex-token-dashboard.ps1
```

Только обновить снимок:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\refresh-codex-token-usage.ps1
```

Удалить почасовую задачу:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\uninstall-codex-token-usage-refresh-task.ps1
```

Удаление задачи не удаляет репозиторий и ваши локальные снимки.

## Производительность

Первый запуск читает доступную историю Codex и может занять заметное время.
Дальше сборщик использует локальный инкрементальный кэш: неизменившиеся сессии
не разбираются заново, а дописанные файлы читаются с сохранённой позиции.
Диагностика и длительность каждого обновления записываются в
`logs/codex-token-usage-refresh.log`.

## Приватность

Снимок `data/codex-token-usage-data.js` содержит реальные названия задач,
рабочие папки, идентификаторы тредов, токены и данные лимитов. Кэш и журнал тоже
локальны. Всё это исключено из Git и не входит в репозиторий.

Дэшборд не отправляет данные наружу и не требует ключей доступа. Подробности:
[PRIVACY.md](PRIVACY.md).

## Структура

- `codex-token-dashboard.html` - интерфейс;
- `tools/export-codex-token-usage.ps1` - сбор и агрегация локальных данных;
- `refresh-codex-token-usage.ps1` - безопасное обновление с блокировкой и логом;
- `install.ps1` - установка одним запуском;
- `install-codex-token-usage-refresh-task.ps1` - почасовая задача Windows;
- `open-codex-token-dashboard.ps1` - обновление и открытие;
- `data/` и `logs/` - только локальные сгенерированные файлы.
